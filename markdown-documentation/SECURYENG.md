## 🚨 2. Reporting a Vulnerability

If you discover a security vulnerability, a game-breaking bug, system instability, or anything that could be misused, please follow the steps below 🔍🐛

### Step 1: Do Not Publicly Disclose Critical Issues Immediately 🤐🛡️
* If an issue affects gameplay systems, multiplayer rooms, or player data, **please avoid posting exploit details or reproduction steps publicly right away** so other players stay protected.

### Step 2: Choose a Reporting Channel 📩
* **General Bugs / UI Issues / Gameplay Glitches:** Open a new **Issue** in the GitHub Repository (`iscursordub-star/khangkhaawkinklwy-nightmare`) 📝
* **Critical or Sensitive Security Issues:** Contact the project maintainer privately via the social links or profile details listed on the project page 🔒

### Step 3: Provide Clear Details for Faster Fixes 🧩
Please include as much helpful information as possible when reporting:
1. **Summary & Description:** What happened and which part of the game is affected 🎯
2. **Steps to Reproduce:** Exact actions or sequence that triggers the issue (e.g., Step 1 -> Step 2 -> Step 3) 🔄
3. **Environment:**
   * Device used (e.g., Desktop PC, Laptop, Android / iOS phone) 💻📱
   * Operating System (e.g., Windows 11, Android) 🖥️
   * Browser used to play (e.g., Chrome, Edge, Safari) 🌐
4. **Supporting Evidence:** Screenshots, short screen recordings, or console error logs (if available) 📸🎥

---

## ⏱️ 3. Response & Disclosure Process

Once a report is received, maintenance follows this workflow ⚙️

* **📩 Acknowledgment:** Initial review and response confirming receipt within **1–3 days**
* **🔍 Investigation:** Reproducing the issue and tracing the root cause in the code
* **🛠️ Patch & Fix:** Writing a fix, testing stability, and pushing updates to the latest version
* **🎉 Resolution:** Notifying the reporter once resolved, with credit given if desired 🌟
